## 0. Prerequisites

- An active Lemlist account with email campaigns set up
- A prospect table in Airschool with enriched email addresses
- Lemlist API access (available on most Lemlist plans)

## 1. Click on "Export"

![Export your leads to Lemlist — 1. Click on "Export"](/images/docs/JhGjlM4TkNoRsWNAASC2x8R53g.png)

## 2. Select "Add a contact to a campaign in Lemlist"

![Export your leads to Lemlist — 2. Select "Add a contact to a campaign in Lemlist"](/images/docs/uC3d83fBGj4GhoMmKgObwpAvWc.png)

## 3. Select the rows to export

![Export your leads to Lemlist — 3. Select the rows to export](/images/docs/UEonB9KWdz1yuakW2dJPf7Vdow.png)

## 4. Connect your Lemlist account

If this is your first time connecting to Lemlist:

1. **Click "Connect your Lemlist account"** in the workflow panel
2. **Note that "No account connected"** appears initially
3. **You'll need to create an API key** in your Lemlist account first

![Export your leads to Lemlist — 4. Connect your Lemlist account](/images/docs/YcPBdkQoQiHcopujVpCV5224AY.png)

## 5. Create API Key in Lemlist settings

**Log into your Lemlist account:**

1. **Click on "Settings"**
2. **Navigate to the "Lemlist API Key"** section
3. **Copy the generated API key** from Lemlist

![Export your leads to Lemlist — 5. Create API Key in Lemlist settings](/images/docs/WcXYGXuuhJkUuDt3NIMqMsZDkR4.png)

![Export your leads to Lemlist — 5. Create API Key in Lemlist settings](/images/docs/e95yeHv43bOW7qxMfCkwhx3ItKI.png)

![Export your leads to Lemlist — 5. Create API Key in Lemlist settings](/images/docs/SlgDQgc4zCCVQSZxAxtBwToXhM.png)

![Export your leads to Lemlist — 5. Create API Key in Lemlist settings](/images/docs/MZpju2ocQJuvtrk1st1gi1l84.png)

## 6. Paste API key in Lemlist and connect

**Return to Airschool** and the export workflow

1. **Paste your Lemlist API key** in the provided field
2. **Click "Connect"** to establish the integration
3. **Wait for confirmation** that the connection was successful

![Export your leads to Lemlist — 6. Paste API key in Lemlist and connect](/images/docs/RPr2xhZm3dXeJFvDH2QifeXblYY.png)

## 7. Select a campaign

![Export your leads to Lemlist — 7. Select a campaign](/images/docs/ARz1NJCKOwu1JzFhYIKmzYeZpg8.png)

## 8. Launch your export

Configure how Airschool data maps to Lemlist fields:

- **Email address** ↔ Lemlist email field
- **First name** ↔ Lemlist first name field
- **Last name** ↔ Lemlist last name field
- **Phone** ↔ Lemlist phone field
- **Company Name** ↔ Lemlist company name field
- **Linkedin Profile URL** ↔ Lemlist linkedin profile field
- **Additional custom fields** as needed

![Export your leads to Lemlist — 8. Launch your export](/images/docs/zfCOKi8Rd2yjTE3FkvoQg6ldlh0.png)
