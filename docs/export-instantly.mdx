## 0. Prerequisites

- An active Instantly account with email campaigns set up
- A prospect table in Airscale with enriched email addresses
- Instantly API access (available on most Instantly plans)

## 1. Click on "Export"

![Export your leads to Instantly — 1. Click on "Export"](/images/docs/LYD5VGZ6VGlzyFXpaOiBjzoY.png)

## 2. Select "Add a contact to a campaign in Instantly"

![Export your leads to Instantly — 2. Select "Add a contact to a campaign in Instantly"](/images/docs/IBoQ0zfJHEjaQGtuWU8MLCHFo.png)

## 3. Select the rows to export

![Export your leads to Instantly — 3. Select the rows to export](/images/docs/pSEFwHCK7m1mVv45PNXb3Z6AGsE.png)

## 4. Connect Your Instantly Account

If this is your first time connecting to Instantly:

1. **Click "Connect your Instantly account"** in the workflow panel
2. **Note that "No account connected"** appears initially
3. **You'll need to create an API key** in your Instantly account first

![Export your leads to Instantly — 4. Connect Your Instantly Account](/images/docs/BJPkLZHrV5BC8OR4Swf5F9srXY.png)

## 5. Create API Key in Instantly Settings

**Log into your Instantly account**

1. **Click on "Settings"** (usually in the left sidebar or user menu)
2. **Navigate to "Integrations"** tab
3. **Select "API Keys"** from the available options

![Export your leads to Instantly — 5. Create API Key in Instantly Settings](/images/docs/N1GreSqI72jIlc9dMpMN3QfrzPE.png)

![Export your leads to Instantly — 5. Create API Key in Instantly Settings](/images/docs/aKE7m60wMfe3sd06KG46yD84.png)

## 6. Create your API key

**Click "Create API Key"** button

1. **Name your API key:** Enter a descriptive name like "Export Airscale" or "Airscale Integration"
2. **Select scopes:** Choose "all:all" for full access (required for campaign management)
3. **Click "Create"** to generate your API key

![Export your leads to Instantly — 6. Create your API key](/images/docs/N90KWeh7OLtG5LsoCRe69owG4.png)

![Export your leads to Instantly — 6. Create your API key](/images/docs/QDje3IbObJw8CHvyTrXLuHVUSlU.png)

## 7. Copy your API key

**Copy the generated API key** from the success popup

1. **Store it securely** - you won't be able to see it again after closing the popup
2. **The API key will be a long string** of characters (similar to: "ZWZIYTA4MTktZmZmYy0DNjFmLTk5ZTEtMWJmOWEyNzY4NTFiOmpzWlJYmlb3p...")

**Warning** : copy the API key **immediately** as Instantly won't show it again for security reasons

![Export your leads to Instantly — 7. Copy your API key](/images/docs/YyvBKQgtrr4G7kAVhr6qzOlQ.png)

## 8. Paste API key in Airscale and connect

**Return to Airscale** and the export workflow

1. **Paste your Instantly API key** in the provided field
2. **Click "Connect"** to establish the integration
3. **Wait for confirmation** that the connection was successful

![Export your leads to Instantly — 8. Paste API key in Airscale and connect](/images/docs/2vr8nxATO35rIql8lwQBlEhg.png)

## 9. Select a campaign

![Export your leads to Instantly — 9. Select a campaign](/images/docs/xS9vdSDofJIrwlMIQ9N5qxH28I.png)

## 10. Launch your export

Configure how Airscale data maps to Instantly fields:

- **Email address** ↔ Instantly email field
- **First name** ↔ Instantly first name field
- **Last name** ↔ Instantly last name field
- **Phone** ↔ Instantly phone field
- **Company Name** ↔ Instantly company name field
- **Website** ↔ Instantly website field
- **Additional custom fields** as needed

![Export your leads to Instantly — 10. Launch your export](/images/docs/gnkKiYvdTb90iLqYJf2yJ8k2hk.png)
