## 0. Prerequisites

- An active Smartlead account with email campaigns set up
- A prospect table in Airschool with enriched email addresses
- Smartlead API access (available on most Smartlead plans)

## 1. Click on "Export"

![Export your leads to Smartlead — 1. Click on "Export"](/images/docs/JhGjlM4TkNoRsWNAASC2x8R53g.png)

## 2. Select "Add a contact to a campaign in Smartlead"

![Export your leads to Smartlead — 2. Select "Add a contact to a campaign in Smartlead"](/images/docs/QAKJYg2qo7Nngp19wWHhHa5HXo.png)

## 3. Select the rows to export

![Export your leads to Smartlead — 3. Select the rows to export](/images/docs/bfMmjQZIVApmD0MLfp5SKPTdyI.png)

## 4. Connect your Smartlead account

If this is your first time connecting to SmartLead:

1. **Click "Connect your Smartlead account"** in the workflow panel
2. **Note that "No account connected"** appears initially
3. **You'll need to create an API key** in your Smartlead account first

![Export your leads to Smartlead — 4. Connect your Smartlead account](/images/docs/sNL46NsbdYR1jrzLPtoUCju2M5E.png)

## 5. Create API key in Smartlead settings

**Log into your Smartlead account:**

1. **Click on "Settings"** (usually in the top right corner)
2. **Navigate to the "Smartlead API Key"** section
3. **Copy the generated API key** from Smartlead

![Export your leads to Smartlead — 5. Create API key in Smartlead settings](/images/docs/wuWRy51L1fwHPRETONCEaGigP0.png)

![Export your leads to Smartlead — 5. Create API key in Smartlead settings](/images/docs/OxidZfNkf8receHQFIK656EsMsM.png)

## 6. Paste API key in Airschool and connect

**Return to Airschool** and the export workflow

1. **Paste your Smartlead API key** in the provided field
2. **Click "Connect"** to establish the integration
3. **Wait for confirmation** that the connection was successful

![Export your leads to Smartlead — 6. Paste API key in Airschool and connect](/images/docs/nTWvj01RnjDgpeRnPaeqElRed7k.png)

## 7. Select a campaign

![Export your leads to Smartlead — 7. Select a campaign](/images/docs/ZBLBsHAN3Z1fVIVGgeahgBfnu2s.png)

## 8. Launch your export

Configure how Airschool data maps to SmartLead fields:

- **Email address** ↔ Smartlead email field
- **First name** ↔ Smartlead first name field
- **Last name** ↔ Smartlead last name field
- **Phone** ↔ Smartlead phone field
- **Company Name** ↔ Smartlead company name field
- **Website** ↔ Smartlead website field
- **Linkedin Profile URL** ↔ Smartlead linkedin profile field
- **Additional custom fields** as needed

![Export your leads to Smartlead — 8. Launch your export](/images/docs/kfsTmZZTUSzv1pUr5E7OWcl0HY.png)
