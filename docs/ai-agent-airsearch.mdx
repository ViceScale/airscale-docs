![AI agent (AirSearch) — 3. Select the mode "Web access"](/images/docs/z5fVsD7Ktro54HbAchh08EreJM.png)

## 4. Write or import your prompt

![AI agent (AirSearch) — 4. Write or import your prompt](/images/docs/mdIvWqzGETa0VijChFk2dKyYGqs.png)

## 5. Run the workflow

![AI agent (AirSearch) — 5. Run the workflow](/images/docs/w6WwJXyF506gUi8bQFysN9ErAI8.png)

## 6. Access the results

**Note**: after launching the enrichment, **two columns will be automatically created** on the right side of the spreadsheet

**In the first column that is created,** you’ll find details about the AI’s reasoning behind the answer. If you click on **“Click to expand,”** you can view the full enrichment details

The enrichment will return 4 keys:

- **Response**: the output for your prompt
- **Reasoning**: the steps taken by the agent to return the output
- **Sources**: the web pages visited in order to gather the data to return the output
- **Confidence score**: a score of confidence to understand how reliable and accurate the output is
