##### When to export as CSV

- To launch **email campaigns** in external tools
- To **import data into CRMs** not directly integrated with Airschool
- To **analyze data** in Excel, Google Sheets, or analytics tools
- To **keep local backups** of your prospect data
- To **share prospect lists** across teams and departments

## 4. Select a file extension

Note:

**CSV (recommended):**

- Universal compatibility with most email tools and CRMs
- Smaller file size for large datasets
- Easy to open in Excel, Google Sheets, or text editors
- Best for automated imports and integrations

**XLSX:**

- Excel-native format with formatting preservation
- Better for manual data manipulation
- Supports advanced Excel features if needed
- Slightly larger file size
