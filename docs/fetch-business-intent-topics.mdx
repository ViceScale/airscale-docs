**Note**: the required input to fetch company insights is a **LinkedIn company URL**

## 1. Select the enrichment

![Fetch business intent topics — 1. Select the enrichment](/images/docs/C4pX9uFIuzrjGk4jQTLbkKYSv4.gif)

## 2. Select rows & the correct input

Select the rows you would like to include in the enrichment and select the **"Company Linkedin URL"** column as an input.

![Fetch business intent topics — 2. Select rows & the correct input](/images/docs/JsvoeUQFkN55EMj7j948Oe8EmmQ.gif)

## 3. Enter the business topics

Type the business topics you would like to inquire and make sure to **press** **Enter** ↩︎ after typing so the suggestions appear.

Click on **"Add +"** to select the topics.

![Fetch business intent topics — 3. Enter the business topics](/images/docs/oQMFgLVzqsupUgw3oPjrnWNpqo.gif)

## 4. Run the workflow

As soon as you're done selecting the business topics, you can run the workflow.

![Fetch business intent topics — 4. Run the workflow](/images/docs/FvrMieqjMm1jtkEmsamDrbtpbCc.gif)

## 5. Access the results

Acess you results once the enrichment has finished running. Click on **"Click to expand"** for more details about the search and add any field as a column by clicking on **"Add as a column".**

![Fetch business intent topics — 5. Access the results](/images/docs/7n0LuvO1fa3cDouL07F7ouof9lU.gif)
