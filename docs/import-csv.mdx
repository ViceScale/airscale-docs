**Note:** you can only import a maximum of **10,000 rows**

## 1. Click on "Import as a CSV"

![Import a file as a CSV — 1. Click on "Import as a CSV"](/images/docs/Gq3Io7ZhkZS6PcfC2BSMUU7qssk.png)

## 2. Select the file to import

Before importing your file, ensure:

1. **Your file is a CSV file**
2. **Your file does not contain more than 10,000 rows**

## 3. Map your columns to Airscale columns

- Map the column names of your CSV file to Airscale's columns
- Alternatively, you can use **custom fields** if Airscale does not have a pre-built column for your data

![Import a file as a CSV — 3. Map your columns to Airscale columns](/images/docs/hoUGFYXdEDsZ8hJn2tFrMGWhQ.png)

## 4. Click on "Upload Now" to create a table

![Import a file as a CSV — 4. Click on "Upload Now" to create a table](/images/docs/x3sU5Uve6JB4ChXJEM8r1sOIc9M.png)
