**Note:**

- The required input to find a personal email is a **LinkedIn profile URL**
- If you don't have the LinkedIn profile URL but have a list with first name, last name, and company name, you can use Airschool’s **"Find a LinkedIn profile URL"** or **"Use AI"** enrichments first to retrieve the LinkedIn profile URL
