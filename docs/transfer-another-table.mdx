##### When to export to another table

- Creating campaign segments from a master prospect list
- Organizing prospects by persona (decision makers vs. influencers)
- Separating by geography for territory-based sales teams
- Consolidating data from multiple import sources
- Creating backup tables before running bulk enrichments
- Segmenting by deliverability status for different outreach strategies

## 0. Prerequisites

- A source table containing prospect data in Airscale
- An existing destination table
