## 1. Select the enrichment called "Use AI"

![AI custom prompts — 1. Select the enrichment called "Use AI"](/images/docs/GAiQ1tczEoDfWACoE2AJETsfg3M.png)

## 2. Select the rows to enrich

![AI custom prompts — 2. Select the rows to enrich](/images/docs/WxlDcIeglXVAgqXaSrLz0EO0d0.png)

## 3. Select the mode (web access vs non web access)

![AI custom prompts — 3. Select the mode (web access vs non web access)](/images/docs/brxgtfaR86PzBI94iG9pOoLYxno.png)

**Note**:

- **No web access:** Best to edit, format, or clean your data. Use this mode when your prompt only needs data already existing in your table and doesn’t need to browse the web to provide the expected output
- **Web access:** Use this mode if you want to find data on the web and want AI to have web browsing capabilities. Useful to research data online about a company or a prospect by visiting website pages (*this mode will select Airsearch 1.0 as the LLM to use)*

## 4. Select an LLM

![AI custom prompts — 4. Select an LLM](/images/docs/Uo3HdyDT13L2dqMmgeuNuB68LY.png)

## 5. Write or import your prompt

![AI custom prompts — 5. Write or import your prompt](/images/docs/CgC4NnkSPb9B6BnTib3HN72IM.png)

**Note**: to use dynamically the content of a column existing in your table, **use the key "/" on your keyboard**

## 6. Run the workflow

When the workflow is launched, **a new column will be created with the output**
