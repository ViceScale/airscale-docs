**Note** : you will need to be on a paid plan in order to use Airscale's API

### 1. Sign into Airscale

- [Create an account](https://app.airscale.io/) in Airscale or [Sign in](https://app.airscale.io/)

### 2. Generate your API key

- Head over to your settings and select "API key"
- Alternatively, if you are logged in you can directly access the page [here](https://app.airscale.io/version-live/dashboard?page=settings&tab=key)

### 3. Make your first API call

- Now that you have generated your API key, you can now start enriching your data
- Learn more about [Authentification](/api-reference/authentication) and how to make your first successful API call via "API Endoints"
