## Make your first request

<Steps>
  <Step title="Create an API key">
    In Airscale, open **Settings → API key** and create a key for your server-side application.
  </Step>
  <Step title="Authenticate">
    Store the key in an environment variable and send it as a Bearer token on every request.

    ```bash
    export AIRSCALE_API_KEY="YOUR_API_KEY"
    ```
  </Step>
  <Step title="Request your credit balance">
    Call `POST https://api.airscale.io/v1/credits` with no body.

    ```bash cURL
    curl --request POST \
      --url https://api.airscale.io/v1/credits \
      --header "Authorization: Bearer $AIRSCALE_API_KEY"
    ```
  </Step>
</Steps>

A successful request returns the remaining workspace balance as a number:

```json
{
  "status": "success",
  "response": {
    "credits": 1200
  }
}
```
