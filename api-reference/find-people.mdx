Search for people who match structured profile and company criteria, or count the same audience before retrieving records.

## Contract summary

<Badge color="blue">POST</Badge> `/v1/find-people`

<Badge color="blue">POST</Badge> `/v1/find-people/count`

| Property | Value |
| --- | --- |
| Authentication | Bearer API key |
| Execution | Synchronous |
| Rate limit | 6 requests per second per workspace |
| Request body limit | 256 KiB |
| Search credit cost | 0.1 credits per returned lead; no charge when no leads are returned. |
| Count credit cost | No charge; Count does not debit Airscale credits. |

## Search and Count endpoint comparison

| Endpoint | Outcome | Pagination | Credits |
| --- | --- | --- | --- |
| `POST /v1/find-people` | Returns matching lead records. | `size` and `cursor` | 0.1 credits per returned lead. |
| `POST /v1/find-people/count` | Returns only the matching total. | None | No charge. |

Both endpoints use the same `query` filter contract.

## Request

At least one supported filter is required inside `query`. This is the smallest valid Search request:

```json
{
  "query": {
    "jobTitle": {
      "include": ["Revenue Operations Manager"]
    }
  }
}
```

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `query` | object | Yes | One or more supported filters. |
| `size` | integer | No | Search only. Must be from 1 to 100; defaults to `100`. |
| `cursor` | string | No | Search only. Opaque value from the preceding `next_cursor`. |

Send JSON with `Content-Type: application/json`. Count needs only `query`; omit Search pagination fields from Count requests.

## Filter shapes

### Include and exclude

String filters accept an object with `include`, `exclude`, or both. Maximum 200 values in each array. Every value must be a string.

```json
{
  "jobTitle": {
    "include": ["Founder", "Chief Executive Officer"],
    "exclude": ["Assistant"]
  }
}
```

### Integer range

Integer range filters accept one or more of `>`, `>=`, `<`, or `<=`. Operands must be finite integers.

```json
{
  "currentCompany.headcount": {
    ">": 10,
    "<=": 500
  }
}
```

### Growth

A growth filter requires `timespan` and at least one of `min` or `max`. `timespan` is `6months`, `12months`, or `24months`; growth values can range from -100 through 10000, and `min` cannot exceed `max`.

```json
{
  "currentCompany.headcountGrowth": {
    "min": 20,
    "max": 80,
    "timespan": "12months"
  }
}
```

## Person filters

| Filter | Shape | Matches |
| --- | --- | --- |
| `firstname` | include/exclude | First name. |
| `lastname` | include/exclude | Last name. |
| `jobTitle` | include/exclude | Current job title. |
| `school` | include/exclude | School name. |
| `languages` | include/exclude | Language name or code. |
| `skills` | include/exclude | Skill name. |
| `location` | include/exclude | Person or current-role location. Country names and ISO alpha-2 codes are accepted. |
| `keyword` | include/exclude | Profile text. |
| `totalYearsOfExperience` | integer range | Total years of experience. |
| `timeInCurrentCompany` | integer range | Years at the current company. |

Location filters normalize recognized country names to uppercase ISO alpha-2 codes. Other strings pass through unchanged.

## Current company filters

| Filter | Shape | Matches |
| --- | --- | --- |
| `currentCompanyName` | include/exclude | Current company name. |
| `companyDomain` | include/exclude | Current company domain. URL input is normalized to its hostname. |
| `companyLinkedinUrl` | include/exclude | Current company profile URL or identifier. |
| `currentCompany.type` | include/exclude | Company type. |
| `currentCompany.industry` | include/exclude | Industry. |
| `currentCompany.location` | include/exclude | Headquarters location. |
| `currentCompany.keyword` | include/exclude | Company profile text. |
| `currentCompany.headcount` | integer range | Employee count. |
| `currentCompany.revenue` | integer range | Revenue. |
| `currentCompany.headcountGrowth` | growth | Headcount growth for a supported timespan. |

Values from `companyDomain` and `companyLinkedinUrl` are combined into one current-company identifier filter.

## Pagination

Search returns at most 100 leads per request. When `next_cursor` is not `null`, send it unchanged as `cursor` with the same `query` to fetch the next page. Do not derive or edit cursor contents.

```json
{
  "query": {
    "jobTitle": {
      "include": ["Revenue Operations Manager"]
    }
  },
  "size": 50,
  "cursor": "fp_a1b2c3d4"
}
```

## Search response

A successful Search returns `200 OK` with the total match count, a page of `leads`, and the next cursor.

| Field | Type | Description |
| --- | --- | --- |
| `total` | number | Total number of matching people. |
| `leads` | array | Lead records returned on this page. |
| `leads[].firstname` | string, when available | First name. |
| `leads[].lastname` | string, when available | Last name. |
| `leads[].profileUrl` | string, when available | Professional profile URL. |
| `leads[].jobTitle` | string, when available | Current job title. |
| `leads[].companyName` | string, when available | Current company name. |
| `next_cursor` | string or null | Opaque token for the next page, or `null` at the end. |

Additional lead fields can be present when data is available.

```json
{
  "total": 124,
  "leads": [
    {
      "firstname": "Jordan",
      "lastname": "Lee",
      "profileUrl": "https://www.linkedin.com/in/jordan-lee-example",
      "jobTitle": "Revenue Operations Manager",
      "companyName": "Northstar Labs"
    }
  ],
  "next_cursor": "fp_a1b2c3d4"
}
```

## Count response

A successful Count request returns `200 OK` with only `total`.

| Field | Type | Description |
| --- | --- | --- |
| `total` | number | Total number of matching people. |

```json
{
  "total": 124
}
```

## Errors

| Status | Cause | Recovery |
| --- | --- | --- |
| `400 Bad Request` | Invalid JSON, a missing or invalid `query`, an unsupported filter, an invalid filter shape, invalid `size`, or a non-string `cursor`. | Read the response `details`, keep only a supported filter, and send its valid shape. |
| `401 Unauthorized` | The Bearer token is missing or invalid. | Copy the current key from Airscale Settings and update the server-side secret. |
| `403 Forbidden` | Search has fewer than 0.1 credits available or its credit reservation cannot be completed. | Add credits before retrying Search, or use free Count when only the audience size is needed. |
| `404 Not Found` | The HTTP method or path does not match either public endpoint. | Use `POST` with one of the documented paths. |
| `413 Content Too Large` | The request body exceeds 256 KiB. | Reduce the number of filter values or split the audience into smaller requests. |
| `429 Too Many Requests` | The workspace sent more than 6 requests in the current second. | Retry in the next second with bounded exponential backoff. |
| `502 Bad Gateway` | The downstream search service is unreachable. | Retry the same request with bounded exponential backoff. |
| `503 Service Unavailable` | API-key validation or the credit service is temporarily unavailable. | Retry the same request with bounded backoff; a failed attempt does not return charged leads. |

## Rate limits and credits

| Rule | Value |
| --- | --- |
| Requests | 6 per second per workspace across Search and Count. |
| Request body | 256 KiB maximum. |
| Values per `include` or `exclude` array | 200 maximum. |
| Search page size | 1 to 100; default 100. |
| Search billing | 0.1 credits for each lead returned. Empty result pages are not charged. |
| Count billing | Free. The Count path neither reserves nor debits Airscale credits. |

## Examples

<CodeGroup>
```bash cURL
curl --request POST "https://api.airscale.io/v1/find-people" \
  --header "Authorization: Bearer $AIRSCALE_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "query": {
      "jobTitle": { "include": ["Revenue Operations Manager"] },
      "location": { "include": ["France"] }
    },
    "size": 25
  }'
```

```javascript Node.js
const response = await fetch("https://api.airscale.io/v1/find-people", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.AIRSCALE_API_KEY}`,
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    query: {
      jobTitle: { include: ["Revenue Operations Manager"] },
      location: { include: ["France"] }
    },
    size: 25
  })
});

console.log(await response.json());
```
</CodeGroup>
