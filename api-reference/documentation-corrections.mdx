The API reference now describes the contracts below explicitly. These are corrections and clarifications to the previous documentation, not an announcement that these API behaviors changed when the documentation moved.

| Operation | Previous documentation | Contract to use |
| --- | --- | --- |
| [Credit count](/api-reference/credit-count) | Top-level `credits` string. | Read the numeric balance from `response.credits`. |
| [Bulk email](/api-reference/email-finder-(bulk)) | HTTP `200` on acceptance. | Expect HTTP `202` with `status: "accepted"`; process one webhook callback per item. |
| [Personal email](/api-reference/personal-email) | Required-field table named `email`. | Send `linkedin_profile_url`. |
| [Reverse phone](/api-reference/reverse-phone) | Required-field table named `email`. | Send `mobile_phone`. |
| [Reverse email](/api-reference/reverse-email) | Profile shown in a `body` wrapper. | A match returns a profile directly; a miss returns the JSON string `"not found"`. |
| [People profile](/api-reference/extract-people-profile) and [Company profile](/api-reference/extract-company-profile) | Incomplete `body`-wrapped examples and optional webhook hints. | Read the returned profile directly. Omit `mode` for the default workflow, or use `p2`/`p3` for normalized output. `webhook_url` is not part of this request contract. |
| [Find companies](/api-reference/find-companies) | Largest preset buckets lacked `+`. | Use `10001+`, `10T+`, `20+`, and `1001+` for employee size, revenue, age, and location count. |
| [Airsearch](/api-reference/airsearch) | Found and not-found results both described as costing one credit. | Only `success` costs one credit. `not_found` and `timeout` are not charged. |

The previous [DNC Checker](/api-reference/dnc-checker) page listed 3 requests per second; the deployed limit verified for this reference is 5 requests per second per workspace.

## Handle completed requests and failures separately

Airsearch can return HTTP `200` with `status: "timeout"` for a later-stage soft timeout, or HTTP `504` for an initial-stage timeout. Its `response` can be text or an object, and `sources` can include public labels as well as URLs.

Bulk email acceptance does not mean all inputs succeeded. Persist callbacks, reconcile them by `custom_id`, and handle `not_found`, `timeout`, and `error: "insufficient_credits"`. Automatic webhook retries are not guaranteed.

For personal email, a `502` can occur after a result was charged if usage recording fails. Check your balance before retrying that input. Follow each endpoint's retry guidance rather than retrying every error immediately.

The [Leads Finder](/api-reference/leads-finder) and [DNC Checker](/api-reference/dnc-checker) documentation URLs are preserved. Their pages explain the available evidence and integration guidance; moving the documentation does not itself retire an API endpoint.
