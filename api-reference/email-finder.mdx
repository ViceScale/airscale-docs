Identify a person by profile URL or by name and company, then return a verified professional email when one is found.

<Badge color="blue">POST</Badge> `/v1/email`

| Property | Value |
| --- | --- |
| Method | `POST` |
| Endpoint | `https://api.airscale.io/v1/email` |
| Execution | Synchronous |
| Authentication | Bearer API key |
| Rate limit | 3,000 requests per minute per workspace |
| Request body limit | 256 KiB |
| Airscale credit cost | 2 credits only when the response has `status: "success"`; `not_found` is not charged. |

## Request

Send JSON and identify the person in one of two ways:

1. Set `linkedin_profile_url` to a LinkedIn person profile URL.
2. Set `first_name` and `last_name`, plus either `domain` or `company_name`.

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `linkedin_profile_url` | string | Required for profile lookup | LinkedIn person profile URL. |
| `first_name` | string | Required for name lookup | Person's first name. |
| `last_name` | string | Required for name lookup | Person's last name. |
| `domain` | string | Conditional | Company domain. Provide this or `company_name` for name lookup. URL prefixes and paths are removed. |
| `company_name` | string | Conditional | Company name. Provide this or `domain` for name lookup. |

Profile lookup request:

```json
{
  "linkedin_profile_url": "https://www.linkedin.com/in/example-person-000000"
}
```

Name and company request:

```json
{
  "first_name": "Example",
  "last_name": "Person",
  "domain": "example.com"
}
```

<Note>
The request may contain both forms. At least one complete form must be present.
</Note>

## Response

A successful lookup returns `200 OK`:

```json
{
  "status": "success",
  "email": "example.person@example.com",
  "email_status": "valid",
  "provider": "Airscale",
  "verifier": "Bounceban",
  "catch_all": "no",
  "linkedin_profile_url": "https://www.linkedin.com/in/example-person-000000"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `status` | string | `success` or `not_found`. |
| `email` | string or null | Verified professional email, or `null` when no result is found. |
| `email_status` | string | `valid` on a successful result. |
| `provider` | string | Public source label for the result. |
| `verifier` | string | Public verification-service label. |
| `catch_all` | string | `yes` or `no`. |
| `linkedin_profile_url` | string | Echoed only when a recognized LinkedIn URL was supplied in the request. |

When no verified email is found, the endpoint still returns `200 OK` and does not charge credits:

```json
{
  "status": "not_found",
  "email": null
}
```

## Errors

| Status | Cause | Recovery |
| --- | --- | --- |
| `400 Bad Request` | The JSON is invalid or neither identification form is complete. | Send valid JSON with a profile URL, or with first name, last name, and a domain or company name. |
| `401 Unauthorized` | The Bearer token is missing or invalid. | Add the current workspace API key to the `Authorization` header. |
| `403 Forbidden` | The workspace has fewer than 2 credits. | Add credits before retrying. |
| `413 Content Too Large` | The request body exceeds 256 KiB. | Remove unrelated fields and resend the request. |
| `429 Too Many Requests` | The workspace reached 3,000 requests in the current minute. | Retry after the minute window with bounded exponential backoff. |
| `502 Bad Gateway` | API-key validation is temporarily unavailable. | Retry with bounded backoff; verify the same key through the credit-count endpoint if the error persists. |
| `503 Service Unavailable` | A successful result could not be settled by the credit service. | Retry with the same input after the service recovers. |
| `500 Internal Server Error` | An unexpected worker error occurred. | Retry once with bounded backoff, then contact support with the response status and timestamp. |

## Examples

<CodeGroup>
```bash cURL
curl --request POST \
  --url https://api.airscale.io/v1/email \
  --header "Authorization: Bearer $AIRSCALE_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "first_name": "Example",
    "last_name": "Person",
    "company_name": "Example Labs"
  }'
```

```python Python
import os
import requests

response = requests.post(
    "https://api.airscale.io/v1/email",
    headers={"Authorization": f"Bearer {os.environ['AIRSCALE_API_KEY']}"},
    json={
        "first_name": "Example",
        "last_name": "Person",
        "company_name": "Example Labs",
    },
    timeout=100,
)
response.raise_for_status()
print(response.json())
```

```javascript Node.js
const apiKey = process.env.AIRSCALE_API_KEY;
const response = await fetch("https://api.airscale.io/v1/email", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${apiKey}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    first_name: "Example",
    last_name: "Person",
    company_name: "Example Labs",
  }),
});

if (!response.ok) throw new Error(`Email lookup failed with HTTP ${response.status}`);
console.log(await response.json());
```
</CodeGroup>
