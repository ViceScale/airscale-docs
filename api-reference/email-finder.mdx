Identify one person by LinkedIn profile URL or by name and company, then return a verified professional email when one is found.

<Note>
The limit is 3,000 requests per minute per workspace. A successful result costs 2 credits; `not_found` is not charged.
</Note>

## Which inputs can I send?

All five fields belong to the same request. **You can send them together.** The examples describe minimum information, not mutually exclusive options.

| Information available | Fields to send |
| --- | --- |
| LinkedIn profile URL only | `linkedin_profile_url` |
| Person's name and company name | `first_name`, `last_name`, `company_name` |
| Person's name and company domain | `first_name`, `last_name`, `domain` |
| All of the above | Send all five fields together. |

Send a person's name as `first_name` and `last_name`; `full_name` is not a supported request field. Without a LinkedIn profile URL, both name fields and a company name or domain are required. Company name alone or a person's name alone does not meet the current API's minimum input requirement.

The success example includes all documented response fields. `provider` and `verifier` use placeholder labels; optional fields may be absent from a result.

<Warning>
For temporary `502` or `503` responses, use a limited number of retries with increasing delays. If errors persist, stop retrying and contact support. A client timeout does not confirm whether the request completed or was charged.
</Warning>
