---
title: "Reverse email"
description: "Find a person profile from an email address."
canonical: "https://airscale.mintlify.app/api-reference/reverse-email"
openapi: "/openapi.json POST /v1/reverse-email"
---

Submit an email address and receive the matching person profile when one can be resolved.

<Note>
The limit is 25 requests per second per workspace. A returned profile costs 2 credits. A miss returns the JSON string `"not found"`, not an object with a status field, and is not charged.
</Note>

After a `429 Too Many Requests` response, retry in a later second with bounded exponential backoff. A `503` transport or settlement failure is not charged; retry the same email with bounded backoff after the dependency recovers.

## Next step

Use [Reverse phone](/api-reference/reverse-phone) when a phone number is the identifier you have for a person.
