---
title: "Reverse email"
description: "Find a person profile from an email address."
---

Submit an email address and receive the matching person profile when one can be resolved.

<Badge color="blue">POST</Badge> `/v1/reverse-email`

| Property | Value |
| --- | --- |
| Method | `POST` |
| Endpoint | `https://api.airscale.io/v1/reverse-email` |
| Execution | Synchronous |
| Authentication | Bearer API key |
| Rate limit | 25 requests per second per workspace |
| Request body limit | 256 KiB |
| Airscale credit cost | 2 credits only when a profile is returned; `"not found"` and errors are not charged. |

## Request

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `email` | string | Yes | Email address to resolve. |

The email is trimmed and converted to lowercase. It must contain a non-empty local part, an `@`, and a domain with at least one dot.

```json
{
  "email": "example.person@example.com"
}
```

## Response

A successful lookup returns `200 OK` with a top-level profile object. The exact profile data depends on the information available, while `url` and `identifier` are normalized when a professional profile URL is known.

```json
{
  "id": "person-example-000000",
  "identifier": "example-person-000000",
  "profile": {
    "fullName": "Example Person",
    "headline": "Example role at Example Labs"
  },
  "link": {
    "linkedin": "https://www.linkedin.com/in/example-person-000000"
  },
  "url": "https://www.linkedin.com/in/example-person-000000"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `url` | string or null | Canonical professional profile URL when one is known. |
| `identifier` | string or null | Public profile slug when one can be derived. |
| `profile` | object, when available | Structured profile fields present in the resolved record. |
| Additional profile fields | varies | Other top-level person fields returned with the available record. |

When no profile matches, the endpoint returns `200 OK` with the JSON string `"not found"`. This is not an object with a `status` field, and the lookup does not charge credits.

```json
"not found"
```

## Errors

| Status | Cause | Recovery |
| --- | --- | --- |
| `400 Bad Request` | The JSON is invalid or `email` is missing or invalid. | Send a syntactically valid email such as `example.person@example.com`. |
| `401 Unauthorized` | The Bearer token is missing or invalid. | Add the current workspace API key to the `Authorization` header. |
| `403 Forbidden` | The workspace has fewer than 2 credits, or the balance cannot cover settlement. | Add credits before retrying. |
| `413 Content Too Large` | The request body exceeds 256 KiB. | Remove unrelated fields and resend the request. |
| `429 Too Many Requests` | The workspace reached 25 requests in the current second. | Retry in a later second with bounded exponential backoff. |
| `502 Bad Gateway` | API-key validation is temporarily unavailable. | Confirm the API key, then retry with bounded backoff. |
| `503 Service Unavailable` | Lookup transport or credit settlement is temporarily unavailable. | Retry the same email with bounded backoff; a 503 response is not charged. |
| `500 Internal Server Error` | Required server configuration is unavailable or an unexpected worker error occurred. | Retry once, then contact support with the timestamp if the error persists. |

## Examples

<CodeGroup>
```bash cURL
curl --request POST \
  --url https://api.airscale.io/v1/reverse-email \
  --header "Authorization: Bearer $AIRSCALE_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{"email":"example.person@example.com"}'
```

```python Python
import os
import requests

response = requests.post(
    "https://api.airscale.io/v1/reverse-email",
    headers={"Authorization": f"Bearer {os.environ['AIRSCALE_API_KEY']}"},
    json={"email": "example.person@example.com"},
    timeout=60,
)
response.raise_for_status()
print(response.json())
```

```javascript Node.js
const apiKey = process.env.AIRSCALE_API_KEY;
const response = await fetch("https://api.airscale.io/v1/reverse-email", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${apiKey}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({ email: "example.person@example.com" }),
});

if (!response.ok) throw new Error(`Reverse-email lookup failed with HTTP ${response.status}`);
console.log(await response.json());
```
</CodeGroup>
