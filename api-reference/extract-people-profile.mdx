Extract a structured person profile from a recognized LinkedIn URL, normally an `/in/` profile.

<Note>
The limit is 3,000 requests per minute per workspace. The submitted URL selects the response schema and successful-call credit cost: `/in/` successes cost 1 credit by default, while `/company/` and `/school/` successes cost 0.5 credits. Workspace-specific pricing can differ, and unsuccessful requests are not charged.
</Note>

The optional modes are `p1`, `p2`, and `p3`. Omit `mode` for the default extraction workflow, whose successful shape can vary; use `p2` or `p3` when you need the normalized schema. The submitted URL, not the route name, selects person versus company output.

Extraction failures return an error rather than a `200 OK` no-result envelope. Retry transient extraction or settlement failures with bounded backoff, and omit `mode` if you do not require a specific mode.
