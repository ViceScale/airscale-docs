---
title: "People profile"
description: "Extract a structured person profile from a professional profile URL."
---

Submit a professional profile URL and receive normalized identity, location, experience, education, and skills data.

<Badge color="blue">POST</Badge> `/v1/profile`

| Property | Value |
| --- | --- |
| Method | `POST` |
| Endpoint | `https://api.airscale.io/v1/profile` |
| Execution | Synchronous |
| Authentication | Bearer API key |
| Rate limit | 3,000 requests per minute per workspace |
| Request body limit | 256 KiB |
| Airscale credit cost | URL-selected: `/in/` successes cost 1 credit by default (workspace-specific pricing may differ); `/company/` or `/school/` successes cost 0.5 credits; unsuccessful requests are not charged. |

## Request

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `linkedin_profile_url` | string | Yes | Recognized LinkedIn `/in/`, `/company/`, or `/school/` profile URL. The submitted URL determines the response schema and successful-call credit cost; use `/in/` for the person schema shown on this page. |
| `mode` | string | No | Extraction mode. Allowed values are `p1`, `p2`, or `p3`; omit it to use the default extraction workflow. |

The URL is trimmed before validation. URLs without a scheme are accepted, and recognized LinkedIn URLs are normalized to `https://www.linkedin.com/{type}/{slug}`. For a person, use a path with one profile slug after `/in/`.

```json
{
  "linkedin_profile_url": "https://www.linkedin.com/in/example-person-000000"
}
```

## Response

A successful extraction returns `200 OK` with the person profile object at the top level:

```json
{
  "url": "https://www.linkedin.com/in/example-person-000000",
  "identifier": "example-person-000000",
  "entityUrn": "urn:li:fsd_profile:example-person-000000",
  "objectUrn": "example-person-000000",
  "firstname": "Example",
  "lastname": "Person",
  "headline": "Example role at Example Labs",
  "picture": "https://cdn.example.com/profiles/example-person.png",
  "summary": "Builds example products.",
  "industry": "Software",
  "location": {
    "country": "United States",
    "city": "Example City",
    "state": "CA",
    "defaultValue": "Example City, CA, United States",
    "shortValue": "Example City, CA"
  },
  "educations": {
    "totalElements": 0,
    "page": 0,
    "size": 20,
    "contents": []
  },
  "positionGroups": {
    "totalElements": 1,
    "page": 0,
    "size": 10,
    "contents": [
      {
        "company": {
          "name": "Example Labs",
          "domain": "example.com"
        },
        "profilePositions": [
          {
            "title": "Example role"
          }
        ]
      }
    ]
  },
  "skills": {
    "totalElements": 2,
    "page": 0,
    "size": 20,
    "contents": ["Research", "Product development"]
  }
}
```

| Field | Type | Description |
| --- | --- | --- |
| `url` | string or null | Canonical person profile URL. |
| `identifier` | string or null | Public profile slug when available. |
| `firstname` | string or null | Given name. |
| `lastname` | string or null | Family name. |
| `headline` | string or null | Current professional headline. |
| `location` | object | Normalized country, city, state, and display values. |
| `educations` | object | Paginated education records. |
| `positionGroups` | object | Paginated employment groups and their positions. |
| `skills` | object | Paginated skill names. |

The submitted recognized profile URL determines the response schema on either profile route. An `/in/` URL uses the person fields shown above. A `/company/` or `/school/` URL uses the [Company profile](/api-reference/extract-company-profile) response schema instead, even when the request is sent to `/v1/profile`. The URL type also determines the credit cost for a successful call.

The endpoint returns errors rather than a `200 OK` no-result envelope when the submitted profile cannot be extracted. These unsuccessful requests are not charged.

## Errors

| Status | Cause | Recovery |
| --- | --- | --- |
| `400 Bad Request` | The JSON is invalid, `linkedin_profile_url` is missing or malformed, `mode` is not `p1`, `p2`, or `p3`, or the upstream source identifies an invalid profile. | Send valid JSON with a recognized LinkedIn `/in/`, `/company/`, or `/school/` URL, choosing the URL type for the response schema you need. |
| `401 Unauthorized` | The Bearer token is missing or invalid. | Add the current workspace API key to the `Authorization` header. |
| `403 Forbidden` | The workspace cannot cover the successful-call cost selected by the submitted URL type. | Add enough credits for the selected URL type, then retry the request. |
| `404 Not Found` | The profile could not be extracted after the available lookup paths completed. | Confirm that the public profile URL is current and uses the intended profile type. |
| `413 Content Too Large` | The request body exceeds 256 KiB. | Remove unrelated fields and resend the request. |
| `429 Too Many Requests` | The workspace reached 3,000 requests in the current minute. | Retry after the minute window with bounded exponential backoff. |
| `502 Bad Gateway` | API-key validation or upstream configuration is temporarily unavailable. | Confirm the API key, then retry with bounded backoff. |
| `503 Service Unavailable` | The selected extraction path or credit settlement service is temporarily unavailable. | Retry the same URL with bounded backoff; omit `mode` if you do not require a specific mode. |
| `500 Internal Server Error` | An unexpected worker error occurred. | Retry once with bounded backoff, then contact support with the timestamp. |

## Examples

<CodeGroup>
```bash cURL
curl --request POST \
  --url https://api.airscale.io/v1/profile \
  --header "Authorization: Bearer $AIRSCALE_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{"linkedin_profile_url":"https://www.linkedin.com/in/example-person-000000"}'
```

```python Python
import os
import requests

response = requests.post(
    "https://api.airscale.io/v1/profile",
    headers={"Authorization": f"Bearer {os.environ['AIRSCALE_API_KEY']}"},
    json={"linkedin_profile_url": "https://www.linkedin.com/in/example-person-000000"},
    timeout=60,
)
response.raise_for_status()
print(response.json())
```

```javascript Node.js
const apiKey = process.env.AIRSCALE_API_KEY;
const response = await fetch("https://api.airscale.io/v1/profile", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${apiKey}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    linkedin_profile_url: "https://www.linkedin.com/in/example-person-000000",
  }),
});

if (!response.ok) throw new Error(`Profile extraction failed with HTTP ${response.status}`);
console.log(await response.json());
```
</CodeGroup>
