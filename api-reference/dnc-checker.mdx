Submit a US phone number using `phone`. The operation normalizes accepted numbers to `+1` format and returns whether the number is listed on DNC.

<Note>
A successful check costs 1 credit whether `listed` is `true` or `false`. The limit is 5 requests per second per workspace. Validation and lookup failures are not charged.
</Note>

Non-US numbers return `422` with `code: "unsupported_phone_region"` without starting a check. Malformed numbers return `422` with `code: "invalid_input"`. Correct the input before retrying either response.

`phone_number` and `mobile_phone` are accepted aliases. `phone` takes precedence when non-null, followed by `phone_number`, then `mobile_phone`. Use one field to avoid ambiguity.

## Read a successful result

| Field | Meaning |
| --- | --- |
| `status` | `success` for a completed check. |
| `phone` | Normalized US phone number. |
| `listed` | Boolean indicating whether the number is listed. |
| `result` | `Listed on DNC` or `Not listed on DNC`. |
| `credits_used` | Credits charged for this check. |
| `credits_remaining` | Remaining workspace credit balance. |

After `429`, retry in a later second with bounded exponential backoff. For temporary `502` or `503` responses, retry with increasing delays and a fixed retry limit; contact support if errors persist. The maximum JSON body size is 256 KiB.
