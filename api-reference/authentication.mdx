Airscale authenticates API requests with a workspace API key sent as a Bearer token.

## Create an API key

Create the key in **Airscale Settings**: open the [Airscale dashboard](https://app.airscale.io/dashboard), choose **Settings → API key**, and generate a key for your integration.

Store the value in your server's secret manager or environment configuration:

```bash
export AIRSCALE_API_KEY="YOUR_API_KEY"
```

## Send the key

Include this header on every API request:

```text
Authorization: Bearer $AIRSCALE_API_KEY
```

## Handle unauthorized requests

A missing Bearer token or an invalid API key returns `401 Unauthorized`. Check that the header is present, that it starts with `Bearer`, and that your deployed secret contains the current key before retrying.

<Warning>
Keep API keys server-side. Never commit them to source control, place them in examples, or expose them in browser or mobile client bundles.
</Warning>

## Rotate a compromised key

If a key is exposed, rotate it immediately in **Airscale Settings**. Update the server-side secret, deploy the new value, verify an authenticated request, and stop using the old key.

Next, review [Rate limits](/api-reference/rate-limits) before adding request concurrency or retries.
