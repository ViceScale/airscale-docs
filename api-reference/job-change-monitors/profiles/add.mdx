title: "Add profiles to a job-change monitor"
description: "Add up to 10,000 personal LinkedIn profiles per request while preserving existing baselines."
canonical: "https://airscale.mintlify.app/api-reference/job-change-monitors/profiles/add"
openapi: "/openapi.json POST /v1/job-change-monitors/{monitor_id}/profiles"
---

Add one to 10,000 personal LinkedIn profiles per request to an existing monitor. Airschool ignores a URL that is already active and reports how many profiles were actually added. All profiles keep the existing monitor ID, frequency, and webhook.

<Note>
Adding a URL after it was removed creates a new profile and a new baseline. The previous profile's events remain associated with its original profile ID.
</Note>

The response includes the newly created profile records, `added_profile_count`, and the monitor's resulting `active_profile_count`. The 10,000-profile limit applies to the monitor's active profiles after adding new URLs. For example, a monitor with 9,000 active profiles can accept 1,000 more distinct active profiles.

The complete JSON request body must fit within **8 MiB (8,388,608 bytes)** in UTF-8; larger bodies return `413`. Split a larger payload into smaller add requests to the same monitor, keeping its total at or below 10,000 active profiles.

Checks run asynchronously and a large scan can take time. A new profile's first successful check establishes its baseline without emitting a job-change event. Monitoring costs **0.1 credit per profile per check**, using the monitor's weekly, every-30-days, or every-90-days schedule.
