Create an active monitor for one to 500 personal LinkedIn profiles with [Bearer authentication](/api-reference/authentication). The request requires an `Idempotency-Key` so a retry cannot create a duplicate monitor.

<Note>
The `frequency` can be `weekly`, `every_30_days`, or `every_90_days`. If you provide `webhook_url`, store the returned `signing_secret` immediately; it is returned only on the first successful create response.
</Note>

Airschool canonicalizes LinkedIn URLs and preserves each profile's optional `external_id` in later events. Monitoring admission checks the workspace's configured provider, capacity, and credit balance before accepting the monitor.

## Verify webhook signatures

Airscale sends `job_change.detected` as a JSON `POST` to `webhook_url`. The request includes `X-Airscale-Event-Id`, `X-Airscale-Timestamp`, and `X-Airscale-Signature: sha256=<hex>`. Compute HMAC-SHA256 with the one-time `signing_secret` over `<timestamp>.<raw request body>`, compare it in constant time, and reject timestamps older than five minutes. Return a 2xx response only after durable handling. Retries keep the same event ID and use `Idempotency-Key: job-change-event:<event_id>`.
