Build a company audience from validated firmographic, geographic, event, intent, technology, and website criteria.

## Contract summary

<Badge color="blue">POST</Badge> `/v1/find-companies`

<Badge color="blue">GET</Badge> `/v1/find-companies/filter-values`

| Property | Value |
| --- | --- |
| Authentication | Bearer API key |
| Execution | Synchronous |
| Rate limit | 6 requests per second per workspace |
| Request body limit | 256 KiB |
| Search credit cost | 0.1 credits per returned company; no charge when no companies are returned. |
| Filter-values credit cost | No charge. |

## Search and Filter-values endpoint comparison

| Endpoint | Outcome | Input | Credits |
| --- | --- | --- | --- |
| `POST /v1/find-companies` | Returns company records that match the filters. | JSON body | 0.1 credits per returned company. |
| `GET /v1/find-companies/filter-values` | Discovers accepted city, region, industry, topic, or technology values. | Query parameters | No charge. |

Use Filter-values when a Search filter accepts a controlled or location-aware value.

## Request

At least one real filter is required. Defaults such as `eventWindow` and `locationMatch` do not count by themselves. This is the smallest useful Search request:

```json
{
  "filters": {
    "country": ["France"]
  },
  "size": 25
}
```

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `filters` | object | Yes | One or more supported filters. |
| `page` | integer | No | Zero-based request page; defaults to `0`. |
| `size` | integer | No | Must be from 1 to 100; defaults to `50`. |
| `cursor` | string | No | Opaque `fc_` value returned by the preceding response. |

Send JSON with `Content-Type: application/json`.

## Filter field table

String list filters accept either one string or an array of strings. Empty values and duplicates are removed.

| Filter | Type | Category | Validation |
| --- | --- | --- | --- |
| `country` | string or array of strings | Location | Recognized country name or ISO alpha-2 code. |
| `region` | string or array of strings | Location | Canonical region code, `Region\|Country`, or a region name scoped by `country`. |
| `city` | string or array of strings | Location | Resolvable value returned by Filter-values, such as `San Francisco, CA, US`. |
| `industry` | string or array of strings | Firmographic | Canonical industry value returned by Filter-values. |
| `size` | string or array of strings | Firmographic | Fixed employee-range value. |
| `revenue` | string or array of strings | Firmographic | Fixed revenue-range value. |
| `age` | string or array of strings | Firmographic | Fixed company-age value. |
| `techStack` | string or array of strings | Technology | Technology value returned by Filter-values. |
| `keywords` | string or array of strings | Website | Text found on the company website. |
| `topics` | string or array of strings | Intent | Canonical business-intent topic returned by Filter-values. |
| `events` | string or array of strings | Event | Fixed recent-event value. |
| `locations` | string or array of strings | Firmographic | Fixed number-of-locations range. |
| `companyName` | string or array of strings | Firmographic | Company name. |
| `eventWindow` | string | Event | `30 days`, `60 days`, or `90 days`; defaults to `30 days`. |
| `locationMatch` | string | Location | `hqOnly` or `hqOperating`; defaults to `hqOnly`. |
| `hasWebsite` | boolean or null | Website | `true`, `false`, or `null`. |
| `isPublicCompany` | boolean or null | Firmographic | `true`, `false`, or `null`. |

Unsupported keys are rejected. `googleCategory`, `naicsCategory`, and `techStackCategory` are not Search filters; use `industry` or `techStack` instead.

## Filter discovery

Filter-values accepts the following query parameters:

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `filter` | string | Yes | `city`, `region`, `industry`, `topics`, or `techStack`. |
| `q` | string | Yes | Search text from 2 to 120 characters. `query` is also accepted. |
| `limit` | integer | No | Omitted, non-numeric, or non-integer values default to `20`; an explicit empty `?limit=` converts to `0` and clamps to `1`; integers below `1` clamp to `1`, and integers above `100` clamp to `100`. |
| `country` | string | No | Repeat or comma-separate country context. |
| `region` | string | No | Repeat or comma-separate region context. A bare region name needs country context. |

The response identifies the filter and query and returns normalized options. Option fields depend on whether values come from a local canonical list or autocomplete.

| Field | Type | Presence | Description |
| --- | --- | --- | --- |
| `label` | string | Always | Display text for the option. |
| `value` | string | Always | Value to send in a Search filter. |
| `query` | string | Autocomplete options only | Autocomplete query associated with the option. |
| `city` | string | City options, when resolved | Parsed city name. |
| `region` | string | City or region options, when resolved | Parsed region label. |
| `countryCode` | string | City or region options, when resolved | Lowercase ISO alpha-2 country code. |
| `regionCode` | string | City or region options, when resolved | Canonical region code such as `us-ca`. |

Local industry and topic options contain only `label` and `value`:

```json
{
  "filter": "industry",
  "query": "software",
  "values": [
    {
      "label": "data security software products",
      "value": "data security software products"
    }
  ]
}
```

Autocomplete location options include `query` and any location metadata that can be resolved:

```json
{
  "filter": "city",
  "query": "san",
  "values": [
    {
      "query": "san",
      "label": "San Francisco",
      "value": "San Francisco, CA, US",
      "city": "San Francisco",
      "region": "CA",
      "regionCode": "us-ca",
      "countryCode": "us"
    }
  ]
}
```

Industry and topic discovery use the same response envelope. Technology, city, and region options are deduplicated and filtered by the supplied location context.

## Pagination

For the first request, use `page: 0` and a `size` from 1 to 100. When `next_cursor` is present, send it unchanged as `cursor` with the same filters. Cursor pagination preserves the original page size and can traverse up to 10,000 companies for one search.

```json
{
  "filters": {
    "country": ["France"]
  },
  "size": 100,
  "cursor": "fc_eyJ2IjoxLCJtb2RlIjoic2VhcmNoX2FmdGVyIn0"
}
```

Do not decode, construct, or edit an `fc_` cursor. When a cursor is supplied, its saved page size takes precedence over a new `page` or `size` value.

## Response

A successful Search returns `200 OK`. Each company row is sanitized before it is returned: identifier-like keys and sensitive transport fields are removed recursively.

| Field | Type | Description |
| --- | --- | --- |
| `rows` | array | Sanitized company records for this page. |
| `total` | number | Total number of matches. |
| `page` | number | Page index for this public response. Cursor responses use `0`. |
| `size` | number | Effective page size. |
| `next_cursor` | string or null | Opaque token for the next page, or `null` at the end. |
| `rows[].name` | string, when available | Company name. |
| `rows[].domain` | string, when available | Company domain. |
| `rows[].website` | string, when available | Company website. |
| `rows[].countryName` | string, when available | Country name. |
| `rows[].cityName` | string, when available | City name. |
| `rows[].linkedinProfile` | string, when available | Company profile URL. |

Rows can contain additional business fields when available.

```json
{
  "rows": [
    {
      "name": "Northstar Labs",
      "domain": "northstar.example",
      "website": "https://northstar.example",
      "countryName": "France",
      "cityName": "Paris",
      "linkedinProfile": "https://www.linkedin.com/company/northstar-labs-example"
    }
  ],
  "total": 240,
  "page": 0,
  "size": 25,
  "next_cursor": "fc_eyJ2IjoxLCJtb2RlIjoic2VhcmNoX2FmdGVyIn0"
}
```

## Errors

| Status | Cause | Recovery |
| --- | --- | --- |
| `400 Bad Request` | Invalid JSON, an unknown filter, an unsupported value, invalid `size`, invalid `cursor`, or invalid filter-values parameters. | Read the response `message`, use a supported filter, and select a documented value or Filter-values option. |
| `401 Unauthorized` | The Bearer token is missing or invalid. | Copy the current key from Airscale Settings and update the server-side secret. |
| `403 Forbidden` | Search has fewer than 0.1 credits before execution or credit settlement cannot cover returned rows. | Add credits, then retry Search. |
| `413 Content Too Large` | The request body exceeds 256 KiB. | Remove unused values or split the audience into smaller requests. |
| `429 Too Many Requests` | The workspace sent more than 6 requests in the current second. | Retry in the next second with bounded exponential backoff. |
| `500 Internal Server Error` | A server configuration check or unexpected worker error prevented execution. | Contact Airscale support with the response status and request time. |
| `502 Bad Gateway` | API-key validation, Search, or Filter-values is temporarily unavailable. | Retry the same request with bounded backoff. |
| `503 Service Unavailable` | The credit service could not settle a successful Search. | Retry the same filters after the credit service recovers. |

## Rate limits and credits

| Rule | Value |
| --- | --- |
| Requests | 6 per second per workspace across Search and Filter-values. |
| Request body | 256 KiB maximum for Search. |
| Search billing | 0.1 credits per returned company. Zero returned rows cost zero credits. |
| Search preflight | At least 0.1 credits must be available. |
| Filter-values billing | Free; discovery does not debit credits. |
| Page size | 1 to 100; default 50. |
| Search traversal | Up to 10,000 companies through the opaque cursor flow. |

## Examples

<CodeGroup>
```bash cURL
curl --request POST "https://api.airscale.io/v1/find-companies" \
  --header "Authorization: Bearer $AIRSCALE_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "filters": {
      "country": ["France"],
      "industry": ["software development"],
      "size": ["11-50"]
    },
    "size": 25
  }'
```

```javascript Node.js
const response = await fetch("https://api.airscale.io/v1/find-companies", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.AIRSCALE_API_KEY}`,
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    filters: {
      country: ["France"],
      industry: ["software development"],
      size: ["11-50"]
    },
    size: 25
  })
});

console.log(await response.json());
```
</CodeGroup>

Discover a city value before adding it to Search:

<CodeGroup>
```bash cURL
curl --get "https://api.airscale.io/v1/find-companies/filter-values" \
  --header "Authorization: Bearer $AIRSCALE_API_KEY" \
  --data-urlencode "filter=city" \
  --data-urlencode "q=san" \
  --data-urlencode "country=US" \
  --data-urlencode "region=us-ca" \
  --data-urlencode "limit=10"
```
</CodeGroup>
