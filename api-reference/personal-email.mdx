---

Submit a LinkedIn person profile URL and return a personal email address when one is found.

<Note>
The limit is 2,000 requests per minute per workspace. The minimum balance required to start is 3 credits. A successful result costs between 3 and 12 credits, depending on its source; `not_found` costs 0 credits.
</Note>

<Warning>
A `502 Bad Gateway` response can occur after credits were charged. Check your balance before retrying that input to avoid paying again for the same result.
</Warning>

After checking your balance for a `502`, or for a temporary `503` response, use a limited number of retries with increasing delays. If errors persist, stop retrying and contact support. A client timeout does not confirm whether the request completed or was charged.
