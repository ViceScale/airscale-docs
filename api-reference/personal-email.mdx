Submit a LinkedIn person profile URL and return a personal email address when one is found.

<Note>
The limit is 2,000 requests per minute per workspace. The minimum balance required to start is 3 credits. A successful result costs between 3 and 12 credits, depending on its source; `not_found` costs 0 credits.
</Note>

<Warning>
If a result is found and charged but required usage recording then fails, the operation returns `502 Bad Gateway`. Check your balance before retrying that input to avoid paying again for the same result.
</Warning>

For other transient failures, retry with bounded backoff. Wait for the credit service to recover before retrying a settlement failure.
