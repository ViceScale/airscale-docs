Use this endpoint to read the remaining credit balance for the workspace associated with your API key.

```text
POST https://api.airscale.io/v1/credits
```

| Property | Value |
| --- | --- |
| Method | `POST` |
| Authentication | Bearer API key |
| Request body | None |
| Airscale credit cost | No charge; checking the balance does not debit Airscale credits. |

## Request

Send the API key in the `Authorization` header. Do not send a request body.

<CodeGroup>
```bash cURL
curl --request POST \
  --url https://api.airscale.io/v1/credits \
  --header "Authorization: Bearer $AIRSCALE_API_KEY"
```

```python Python
import os
import requests

response = requests.post(
    "https://api.airscale.io/v1/credits",
    headers={"Authorization": f"Bearer {os.environ['AIRSCALE_API_KEY']}"},
    timeout=30,
)
response.raise_for_status()
print(response.json())
```

```javascript Node.js
const apiKey = process.env.AIRSCALE_API_KEY;
const response = await fetch("https://api.airscale.io/v1/credits", {
  method: "POST",
  headers: { Authorization: `Bearer ${apiKey}` },
});

if (!response.ok) {
  throw new Error(`Credit request failed with HTTP ${response.status}`);
}

console.log(await response.json());
```
</CodeGroup>

## Response

A successful request returns `200 OK` with the remaining credit balance:

```json
{
  "status": "success",
  "response": {
    "credits": 1200
  }
}
```

| Field | Type | Description |
| --- | --- | --- |
| `status` | string | `success` for a successful lookup. |
| `response` | object | Contains the credit lookup result. |
| `response.credits` | number | Credits remaining in the authenticated workspace. |

## Errors

| Status | Cause | Recovery |
| --- | --- | --- |
| `401 Unauthorized` | The Bearer token is missing. | Add the `Authorization` header and resend the request. |
| `401 Unauthorized` | The API key is invalid. | Copy the current key from the Airscale dashboard, verify it matches the deployed value, and update your server-side secret first. Rotate only if the key was exposed. |
