Read the remaining credit balance for the workspace associated with your API key before starting paid enrichment work.

<Note>
Send no request body. Checking the balance is free and does not debit Airscale credits.
</Note>

An invalid or missing key returns `401 Unauthorized`. Confirm the current key in the Airscale dashboard and update your server-side secret; rotate it only if it was exposed.
