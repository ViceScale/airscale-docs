Submit a phone number and receive the matching person profile when one can be resolved.

<Note>
The limit is 2,000 requests per minute per workspace. A returned profile costs 10 credits; `not_found` and errors are not charged.
</Note>

A `not_found` result can represent a true miss or lookup paths that were exhausted or failed. When a match is expected, make one bounded-backoff retry. If it persists, verify that you sent the intended normalized number before retrying again.

For temporary `502` or `503` responses, use a limited number of retries with increasing delays. If errors persist, stop retrying and contact support. A client timeout does not confirm whether the request completed or was charged.

## Read the profile

A match returns the same nested person record as [Reverse email](/api-reference/reverse-email), with **camelCase** keys such as `profile.firstName`, `link.linkedin`, and `positionGroups`. The response also has a `body` field holding a copy of the same record; read either one. When the match comes from a fallback lookup, the record uses the flat fields of [People profile](/api-reference/extract-people-profile) instead.
