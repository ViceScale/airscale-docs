Submit up to 100 people and receive one asynchronous professional-email result per item at your webhook.

<Note>
The limit is 3,000 input items per minute per workspace. Each item with `status: "success"` costs 2 credits; misses and timeouts are not charged.
</Note>

The acceptance response only confirms that the batch was queued. Processing continues after that response, and each item is delivered separately to `webhook_url`.

<Warning>
Return a `2xx` response promptly for every callback. Automatic webhook retries are not part of this operation's contract, so persist callbacks and use `custom_id` to reconcile expected and received results.
</Warning>

If the remaining balance cannot reserve the next item, its callback reports `insufficient_credits`. Add credits before submitting unfinished items again.
