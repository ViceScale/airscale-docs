Identify a person by first name, last name, and company, then return a matching professional profile URL when one is found.

<Note>
The limit is 6 requests per second per workspace. A successful result costs 0.5 credits; `not_found` is not charged.
</Note>

After a `429 Too Many Requests` response, retry in a later second with bounded exponential backoff. Retry transient reservation failures with the same input only after the service recovers.

## Next step

Pass the matched URL to [Email finder](/api-reference/email-finder) for professional email enrichment.
