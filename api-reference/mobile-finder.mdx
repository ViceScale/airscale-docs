---
title: "Mobile finder"
description: "Find a mobile phone number from a professional profile."
---

Submit a LinkedIn person profile URL and return a mobile phone number when one is found.

| Property | Value |
| --- | --- |
| Method | `POST` |
| Endpoint | `https://api.airscale.io/v1/phone` |
| Execution | Synchronous |
| Authentication | Bearer API key |
| Rate limit | 3,000 requests per minute per workspace |
| Request body limit | 256 KiB |
| Airscale credit cost | 40 credits only when the response has `status: "success"`; `not_found` is not charged. |

## Request

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `linkedin_profile_url` | string | Yes | LinkedIn person profile URL used for the lookup. |

```json
{
  "linkedin_profile_url": "https://www.linkedin.com/in/example-person-000000"
}
```

## Response

A successful lookup returns `200 OK`:

```json
{
  "status": "success",
  "linkedin_profile_url": "https://www.linkedin.com/in/example-person-000000",
  "phone_numbers": "+12025550147",
  "provider": "SalesQL"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `status` | string | `success` or `not_found`. |
| `linkedin_profile_url` | string | The profile URL from the request. |
| `phone_numbers` | string or null | One E.164-style phone number on success; otherwise `null`. |
| `provider` | string or null | Public source label on success; otherwise `null`. |

When no mobile number is found, the endpoint returns `200 OK` without charging credits:

```json
{
  "status": "not_found",
  "linkedin_profile_url": "https://www.linkedin.com/in/example-person-000000",
  "phone_numbers": null,
  "provider": null
}
```

## Errors

| Status | Cause | Recovery |
| --- | --- | --- |
| `400 Bad Request` | The JSON is invalid or `linkedin_profile_url` is missing. | Send valid JSON with a non-empty profile URL. |
| `401 Unauthorized` | The Bearer token is missing or invalid. | Add the current workspace API key to the `Authorization` header. |
| `403 Forbidden` | The workspace has fewer than 40 credits. | Add credits before retrying. |
| `413 Content Too Large` | The request body exceeds 256 KiB. | Remove unrelated fields and resend the request. |
| `429 Too Many Requests` | The workspace reached 3,000 requests in the current minute. | Retry after the minute window with bounded exponential backoff. |
| `502 Bad Gateway` | API-key validation is temporarily unavailable. | Retry with bounded backoff after confirming the key is current. |
| `503 Service Unavailable` | A successful result could not be settled by the credit service. | Retry with the same input after the service recovers. |
| `500 Internal Server Error` | An unexpected worker error occurred. | Retry once with bounded backoff, then contact support with the timestamp. |

## Examples

<CodeGroup>
```bash cURL
curl --request POST \
  --url https://api.airscale.io/v1/phone \
  --header "Authorization: Bearer $AIRSCALE_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{"linkedin_profile_url":"https://www.linkedin.com/in/example-person-000000"}'
```

```python Python
import os
import requests

response = requests.post(
    "https://api.airscale.io/v1/phone",
    headers={"Authorization": f"Bearer {os.environ['AIRSCALE_API_KEY']}"},
    json={"linkedin_profile_url": "https://www.linkedin.com/in/example-person-000000"},
    timeout=70,
)
response.raise_for_status()
print(response.json())
```

```javascript Node.js
const apiKey = process.env.AIRSCALE_API_KEY;
const response = await fetch("https://api.airscale.io/v1/phone", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${apiKey}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    linkedin_profile_url: "https://www.linkedin.com/in/example-person-000000",
  }),
});

if (!response.ok) throw new Error(`Mobile lookup failed with HTTP ${response.status}`);
console.log(await response.json());
```
