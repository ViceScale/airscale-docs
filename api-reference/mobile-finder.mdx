Submit a LinkedIn person profile URL and return a mobile phone number when one is found.

<Note>
The limit is 3,000 requests per minute per workspace. A successful result costs 40 credits; `not_found` is not charged.
</Note>

## Phone numbers in the response

- `phone_numbers` is the primary phone number as a single string.
- `all_phone_numbers` is an array of normalized international phone numbers, with duplicates removed and the primary number first. It can contain just the primary number when no additional numbers are available.
- A `not_found` result returns `phone_numbers: null` and `all_phone_numbers: []`.

For temporary `502` or `503` responses, use a limited number of retries with increasing delays. If errors persist, stop retrying and contact support. A client timeout does not confirm whether the request completed or was charged.
