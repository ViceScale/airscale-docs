---
title: "Mobile finder"
description: "Find a mobile phone number from a professional profile."
canonical: "https://airscale.mintlify.app/api-reference/mobile-finder"
openapi: "/openapi.json POST /v1/phone"
---

Submit a LinkedIn person profile URL and return a mobile phone number when one is found.

<Note>
The limit is 3,000 requests per minute per workspace. A successful result costs 40 credits; `not_found` is not charged.
</Note>

Use bounded backoff for transient failures. If a successful result could not be settled by the credit service, retry the same input only after the service recovers.

## Next step

Use [Personal email](/api-reference/personal-email) to look for a personal address from the same profile, or [Reverse phone](/api-reference/reverse-phone) when the phone number is your starting point.
