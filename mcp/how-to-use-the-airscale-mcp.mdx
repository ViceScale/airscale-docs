## Start with a free, bounded workflow

A safe Airscale MCP workflow begins with a free credit check, uses free count or filter discovery where possible, and then runs a narrow sample before any larger request. Review the selected tool's inputs and credit behavior in the [MCP tool catalog](/mcp/tools).

The [Airscale MCP server](/mcp/airscale-mcp-server) overview explains authentication, explicit spend approval, and the asynchronous export lifecycle that applies after the sample is correct.
