## Give agents grounded Airscale context

Agents need machine-readable contracts and clear safety boundaries before they select or approve tools. Use the [MCP tool catalog](/mcp/tools) for the operational server's 22 typed tools and the [Airscale MCP server](/mcp/airscale-mcp-server) page for authentication, credit approval, security, and export lifecycle guidance.

For the HTTP operations that back core MCP tools, use the [API overview](/api-reference/api-overview) as the entry point to the generated API reference.
