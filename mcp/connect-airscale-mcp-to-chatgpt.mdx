Connect ChatGPT to your Airscale workspace with browser OAuth, then verify the connection with a free tool call before you approve any paid work.

## MCP server URL

Use the official remote MCP endpoint exactly as shown:

```text
https://mcp.airscale.io/mcp
```

## What ChatGPT can do with Airscale MCP

Airscale MCP gives ChatGPT 22 typed tools that can:

- Check the authorized workspace's credit balance.
- Search for people and companies.
- Count matches and discover accepted filter values before a paid search.
- Enrich work contact details and extract people or company profiles.
- Run Airsearch web research.
- Create downloadable people or company exports.

Managed large contact enrichment is work-email-only in its current phase. Review exact inputs and credit behavior in the [MCP tool catalog](/mcp/tools).

## Before you start

You need an Airscale account with access to the intended workspace, API access enabled, and an active workspace credential. You also need a ChatGPT account and workspace where Developer mode is available; availability can depend on account and workspace policy.

ChatGPT uses browser OAuth for this connection: if prompted, the browser asks you to sign in to Airscale, choose a workspace, and authorize ChatGPT. OpenAI's [current plugin connection guide](https://developers.openai.com/plugins/deploy/connect-chatgpt) is the source for the navigation below.

After OAuth, Airscale's MCP server resolves the authorized workspace's current credential server-side on each tool call; ChatGPT neither receives nor stores that API key. Do not paste an Airscale API key into ChatGPT, prompts, or tool inputs.

## Step-by-step setup

<Steps>
  <Step title="Enable Developer mode">
    Open **Settings → Security and login**, then turn on **Developer mode**. Developer mode availability can depend on account and workspace policy.
  </Step>
  <Step title="Open ChatGPT Plugins">
    Go to **ChatGPT Plugins** and select the plus button.
  </Step>
  <Step title="Describe the connection">
    Enter a user-facing name and description, such as **Airscale MCP** and a short description of its search, enrichment, research, and export tools.
  </Step>
  <Step title="Connect and authorize Airscale">
    Under **Connection**, choose the public endpoint option and enter `https://mcp.airscale.io/mcp`, including the `/mcp` path. Create the connection. If prompted, complete browser OAuth, sign in to Airscale, select the intended workspace, and return to ChatGPT. Do not enter an API key or static authorization value.
  </Step>
  <Step title="Review discovered tools">
    Review the tools and metadata discovered from the server. Confirm that the Airscale connection shows the expected 22 typed tools before testing it.
  </Step>
  <Step title="Verify the connection for free">
    Start a new conversation, add the Airscale MCP connection from the tools menu, and run `airscale_check_credits` without another tool. A returned balance confirms tool discovery and authentication to an Airscale workspace without debiting credits, but it does not identify which workspace. Separately verify the workspace shown during OAuth before paid actions.
  </Step>
</Steps>

## Recommended first prompts

The identities and domains below are synthetic.

> Use `airscale_check_credits` to show my current Airscale credit balance. Do not call another tool.

This is the free connection test. A returned balance confirms tool discovery and authentication to an Airscale workspace without debiting credits. It does not identify which workspace; verify the workspace shown during OAuth before paid actions.

> Count people named Jordan Example who work at `northstar.example`. Do not run a paid search.

> Plan an Airscale search for up to five companies matching `sample-company.test`. Show the proposed Airscale tool, arguments, and maximum cost, then wait for my approval.

For a complete staged sequence, follow the [safe MCP workflow](/mcp/how-to-use-the-airscale-mcp).

## Export behavior in ChatGPT

A people or company export performs a fresh paid search from the final filters; it does not package the selected chat rows and may return different rows. Before approval, review the exact filters, fields, format, `max_rows`, additional maximum credits, and cumulative workflow maximum.

An export has one asynchronous lifecycle: start the export once, check its status, then retrieve the file when it is ready. Reuse the same `export_id` and honor the returned `poll_after_seconds`. Do not start a duplicate export while the original job is queued or running.

## Credits and confirmation

The credit check, people count, company filter-value discovery, export status, and export-file retrieval are free. Search and enrichment tools can consume credits; Airsearch costs 2 credits per call. Managed contact enrichment is work-email-only in its current phase.

Paid export starts fail closed until `confirm_credit_spend` is explicitly `true`. Review ChatGPT's proposed tool, arguments, row limit, and maximum cost before confirming. An export can support up to 10,000 rows, but use the smallest limit that serves the task.

## Refreshing tools

If Airscale tools or metadata are stale, open the connection in **ChatGPT Plugins**, select **Refresh**, confirm the advertised metadata changed, then start a new conversation and add the connection again from the tools menu.

## Troubleshooting

<AccordionGroup>
  <Accordion title="Developer mode is not visible">
    Open **Settings → Security and login** and look for **Developer mode**. Availability can depend on account and workspace policy, so ask the workspace administrator to check policy if the control is unavailable.
  </Accordion>
  <Accordion title="The connection cannot be created">
    Confirm the exact public endpoint, including the `/mcp` path. Complete Airscale browser authorization if prompted, return to ChatGPT, and review any connection or discovered-tool errors before retrying.
  </Accordion>
  <Accordion title="Authentication succeeds but a tool fails">
    Confirm that the selected Airscale workspace has API access, an active workspace credential, and enough credits for the proposed paid tool. Run `airscale_check_credits` before retrying.
  </Accordion>
  <Accordion title="An export remains queued">
    Poll `airscale_get_export_status` with the same identifier and the returned `poll_after_seconds`. Do not create another paid job.
  </Accordion>
</AccordionGroup>

## Security note

Authorize only the Airscale workspace you intend to use. Keep secrets out of chats and tool inputs, review every proposed paid action, and remove the Airscale MCP connection when it is no longer needed.
