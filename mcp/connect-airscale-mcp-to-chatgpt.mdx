## What this enables

Airscale MCP lets ChatGPT use 22 typed tools for people and company search, contact enrichment, profile extraction, web research, and asynchronous exports. The tools operate against the Airscale workspace you authorize.

## Server URL

Use the official remote MCP endpoint exactly as shown:

```text
https://mcp.airscale.io/mcp
```

## Prerequisites

- An Airscale account with access to the workspace you want to use.
- API access enabled and an active workspace credential in Airscale.
- A Business or Enterprise/Edu workspace on ChatGPT web for the full Airscale MCP tool set.
- The workspace role or developer authorization required to create a custom app.

On ChatGPT web, Business and Enterprise/Edu workspaces can use the full MCP capability, including tools that can take actions. The creation path differs by plan:

- **Business:** An admin or owner must enable developer mode and create the custom app. Developer access cannot currently be delegated to an ordinary Business member.
- **Enterprise/Edu:** Admins and owners can use RBAC to grant developer mode to an authorized developer. Admins or owners still control publication and workspace access.

Pro accounts can use custom apps with read/fetch permissions, but the full MCP flow documented here requires Business or Enterprise/Edu. See OpenAI's current [developer mode and MCP apps guide](https://help.openai.com/en/articles/12584461) before setup.

ChatGPT product availability and UI labels can change. If a label below differs, use the official guide to locate the corresponding developer-mode or app-creation control.

## Authentication

ChatGPT uses browser OAuth for this connection. The browser asks you to sign in to Airscale, select a workspace, and authorize ChatGPT. Do not paste an Airscale API key into ChatGPT. Credentials are never MCP tool arguments.

<Note>
  The selected Airscale workspace still needs API access. Airscale resolves the workspace credential on the server after OAuth; ChatGPT does not configure or store it as part of this setup.
</Note>

## Connect Airscale MCP

<Steps>
  <Step title="Enable developer mode for your role">
    In Business, sign in as an admin or owner and begin from **Workspace settings → Apps → Create**. In Enterprise/Edu, use an admin/owner account or an account that has received developer-mode access through RBAC, then open **Apps → Create** from the available workspace or user settings.
  </Step>
  <Step title="Enter the Airscale endpoint">
    Name the app **Airscale MCP**, enter `https://mcp.airscale.io/mcp` as its MCP endpoint, and provide any other metadata the current form requires.
  </Step>
  <Step title="Choose authentication">
    Select **OAuth** as the authentication mechanism. Do not enter an API key or configure a static authorization header in ChatGPT.
  </Step>
  <Step title="Scan tools and authorize Airscale">
    Click **Scan Tools**, complete the Airscale OAuth flow in the browser, select the intended workspace, and return to ChatGPT. Wait until the tool scan finishes before continuing.
  </Step>
  <Step title="Create the draft">
    Click **Create** only after the scan succeeds. The draft app then appears in the workspace's draft-app list and as a development app in the creator's enabled apps.
  </Step>
  <Step title="Use Airscale for a message">
    Open a new chat and select the draft app from the tools menu, or mention it in the prompt. The selection applies to that message, not the entire conversation; select or mention Airscale again when a follow-up needs a new tool call.
  </Step>
</Steps>

## Verify the connection for free

Make the first request read-only and non-billable:

> Use `airscale_check_credits` to show my current Airscale credit balance. Do not call another tool.

If ChatGPT returns a balance, tool discovery and authentication succeeded. This check does not debit credits, but the balance response does not identify the workspace; the workspace choice occurred in the OAuth flow.

## Starter prompts

These prompts keep the intended tool and scope explicit. The identities and domains are synthetic.

> Use Airscale MCP to count people named Jordan Example who work at `northstar.example`. Do not run a paid search.

> Use `airscale_find_companies_filter_values` to show accepted industry values related to software. Do not call another tool.

> Plan a search for up to five companies matching `sample-company.test`. Show the proposed Airscale tool and arguments, but wait for my approval before running it.

For a complete staged sequence, follow the [safe MCP workflow](/mcp/how-to-use-the-airscale-mcp).

## Credits and approval

The credit check, people count, company filter-value discovery, export status, and export-file retrieval are free. Search and enrichment tools can consume credits; Airsearch costs 2 credits per call. Managed contact enrichment is work-email-only in its current phase.

Paid export starts fail closed until `confirm_credit_spend` is `true`. Before approving one, review the exact filters, `max_rows`, and maximum possible cost. An export can support up to 10,000 rows, but use the smallest limit that serves the task.

<Warning>
  Review ChatGPT's proposed tool name and arguments before approving a paid action. Do not start a second export while the first is queued or running.
</Warning>

## Troubleshooting

<AccordionGroup>
  <Accordion title="Custom MCP controls are not visible">
    Confirm that your ChatGPT account and workspace expose custom remote MCP apps. A workspace administrator may need to enable the feature. Because labels change, check the apps, connectors, or developer settings rather than relying on one menu name.
  </Accordion>
  <Accordion title="The browser authorization does not finish">
    Return to ChatGPT after Airscale displays its confirmation page. If the connection still appears pending, remove it and repeat the OAuth flow while signed in to the intended Airscale workspace.
  </Accordion>
  <Accordion title="Airscale tools do not appear">
    Confirm the server URL, refresh or reconnect the app, and start a new conversation so ChatGPT reloads the MCP tool list.
  </Accordion>
  <Accordion title="Authentication succeeds but a tool fails">
    Confirm that the selected Airscale workspace has API access, an active workspace credential, and enough credits for the proposed paid tool. Re-run `airscale_check_credits` before retrying.
  </Accordion>
  <Accordion title="An export remains queued">
    Keep the same export identifier and ask ChatGPT to poll `airscale_get_export_status` using the returned `poll_after_seconds`. Do not create a duplicate paid job.
  </Accordion>
</AccordionGroup>
