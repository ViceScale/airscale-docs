Connect ChatGPT to your Airscale workspace with browser OAuth, then verify the connection with a free tool call before you approve any paid work.

## MCP server URL

Use the official remote MCP endpoint exactly as shown:

```text
https://mcp.airscale.io/mcp
```

## What ChatGPT can do with Airscale MCP

Airscale MCP gives ChatGPT 22 typed tools that can:

- Check the authorized workspace's credit balance.
- Search for people and companies.
- Count matches and discover accepted filter values before a paid search.
- Enrich work contact details and extract people or company profiles.
- Run Airsearch web research.
- Create downloadable people or company exports.

Managed large contact enrichment is work-email-only in its current phase. Review exact inputs and credit behavior in the [MCP tool catalog](/mcp/tools).

## Before you start

You need an Airscale account with access to the intended workspace, API access enabled, and an active workspace credential. ChatGPT uses browser OAuth for this connection: the browser asks you to sign in to Airscale, choose a workspace, and authorize ChatGPT.

ChatGPT web supports the full MCP flow documented here for Business and Enterprise/Edu workspaces:

- **Business:** An admin or owner must enable developer mode and create the custom app. Developer access cannot currently be delegated to an ordinary Business member.
- **Enterprise/Edu:** Admins and owners can use RBAC to grant developer mode to an authorized developer. Admins or owners still control publication and workspace access.

Pro accounts can use custom apps with read/fetch permissions, but this full MCP setup requires Business or Enterprise/Edu. Check OpenAI's current [developer mode and MCP apps guide](https://help.openai.com/en/articles/12584461) if availability or labels differ.

ChatGPT resolves the selected workspace credential on the Airscale server after OAuth. Do not paste an Airscale API key into ChatGPT, prompts, or tool inputs.

## Step-by-step setup

<Steps>
  <Step title="Enable the app creation controls">
    In Business, sign in as an admin or owner and open **Workspace settings → Apps → Create**. In Enterprise/Edu, use an admin/owner account or an account with developer-mode access through RBAC, then open the available **Apps → Create** control.
  </Step>
  <Step title="Enter the Airscale endpoint">
    Name the app **Airscale MCP** and enter `https://mcp.airscale.io/mcp` as its MCP endpoint. Complete any other metadata required by the current form.
  </Step>
  <Step title="Choose OAuth and scan the tools">
    Select **OAuth**, then click **Scan Tools** and complete the Airscale OAuth flow in the browser: sign in and select the intended workspace. Return to ChatGPT and wait for the scan to finish before continuing. The ChatGPT connection does not need a copied secret or static authorization value.
  </Step>
  <Step title="Create the draft">
    Click **Create** only after the scan succeeds. The draft app appears in the workspace's draft-app list and in the creator's enabled apps.
  </Step>
  <Step title="Select Airscale for a message">
    Open a new chat and select the draft app from the tools menu, or mention it in your prompt. The selection applies to that message, not the entire conversation, so select or mention Airscale again when a follow-up needs another tool call.
  </Step>
  <Step title="Verify the connection for free">
    Ask ChatGPT to use `airscale_check_credits` and no other tool. A returned balance confirms tool discovery and workspace authentication without debiting credits.
  </Step>
</Steps>

## Recommended first prompts

The identities and domains below are synthetic.

> Use `airscale_check_credits` to show my current Airscale credit balance. Do not call another tool.

> Count people named Jordan Example who work at `northstar.example`. Do not run a paid search.

> Plan an Airscale search for up to five companies matching `sample-company.test`. Show the proposed Airscale tool, arguments, and maximum cost, then wait for my approval.

For a complete staged sequence, follow the [safe MCP workflow](/mcp/how-to-use-the-airscale-mcp).

## Export behavior in ChatGPT

A people or company export performs a fresh paid search from the final filters; it does not package the selected chat rows and may return different rows. Before approval, review the exact filters, fields, format, `max_rows`, additional maximum credits, and cumulative workflow maximum.

An export has one asynchronous lifecycle: start the export once, check its status, then retrieve the file when it is ready. Reuse the same `export_id` and honor the returned `poll_after_seconds`. Do not start a duplicate export while the original job is queued or running.

## Credits and confirmation

The credit check, people count, company filter-value discovery, export status, and export-file retrieval are free. Search and enrichment tools can consume credits; Airsearch costs 2 credits per call. Managed contact enrichment is work-email-only in its current phase.

Paid export starts fail closed until `confirm_credit_spend` is explicitly `true`. Review ChatGPT's proposed tool, arguments, row limit, and maximum cost before confirming. An export can support up to 10,000 rows, but use the smallest limit that serves the task.

## Refreshing tools

If Airscale tools are stale or missing, refresh or reconnect the app and start a new conversation so ChatGPT scans the current tool list. Re-select the draft app for the message that should use it.

## Troubleshooting

<AccordionGroup>
  <Accordion title="Custom MCP controls are not visible">
    Confirm that the ChatGPT account and workspace expose custom remote MCP apps. A Business admin or owner may need to enable the feature; Enterprise/Edu access may depend on RBAC.
  </Accordion>
  <Accordion title="Scan Tools does not complete">
    Confirm the exact server URL, finish the Airscale browser authorization, and return to ChatGPT. Remove and reconnect the draft while signed in to the intended Airscale workspace if the scan stays pending.
  </Accordion>
  <Accordion title="Authentication succeeds but a tool fails">
    Confirm that the selected Airscale workspace has API access, an active workspace credential, and enough credits for the proposed paid tool. Run `airscale_check_credits` before retrying.
  </Accordion>
  <Accordion title="An export remains queued">
    Poll `airscale_get_export_status` with the same identifier and the returned `poll_after_seconds`. Do not create another paid job.
  </Accordion>
</AccordionGroup>

## Security note

Authorize only the Airscale workspace you intend to use. Keep secrets out of chats and tool inputs, review every proposed paid action, and remove the app's access when it is no longer needed.
