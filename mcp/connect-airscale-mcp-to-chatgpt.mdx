## Connect ChatGPT through OAuth

ChatGPT connects to the remote Airscale MCP server through a browser OAuth flow. Airscale asks you to sign in and approve workspace access; you do not paste an API key into ChatGPT or include one in tool arguments.

Before connecting, review the [Airscale MCP server](/mcp/airscale-mcp-server) overview and the [MCP tool catalog](/mcp/tools), especially the credit behavior of any tool you plan to approve.
