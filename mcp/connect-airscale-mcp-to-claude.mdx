## Choose the Claude connection model

Claude clients that support remote OAuth can authorize Airscale in the browser. Trusted developer environments can instead use a protected authorization header, with the key supplied by a local environment or secret manager rather than written into prompts or tool arguments.

Start with the [Airscale MCP server](/mcp/airscale-mcp-server) configuration patterns, then use the [MCP tool catalog](/mcp/tools) to review inputs and credit behavior before allowing a tool call.
